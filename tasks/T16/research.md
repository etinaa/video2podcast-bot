## Findings and handoff

1. **Probe before execution, with a bounded worker delay.** Owner A: Q-analyst-2 approves checking on the shared worker after queueing and acknowledgement, immediately before metadata/directory creation. A stalled check may hold following work for HEALTH_TIMEOUT + 1 second; Telegram handling stays responsive. Functional scenarios observe timeout release and current reachability when a waiting job reaches its turn. This supersedes the initial nonblocking-worker interpretation.
2. **Probe reachability is a snapshot.** Healthy startup cannot authorize all future jobs; healthy intake cannot replace inference retries or protect a queued job from a later outage. Tests must distinguish GET probes from POST inference/chat and explicitly keep preflight healthy in mid-job failure fixtures.
3. **Report both failures.** A short circuit after Whisper fails would omit Ollama's result when both are down. Check both and assert the exact combined text from api.md (transcription sentence, then summary sentence).
4. **Health timeouts differ from processing timeouts.** Probe expiry means unavailable before starting work; retain the unreachable message. A stalled inference retains T9/T10's existing timeout text and retries. Separate budgets prevent an apparently working bot hanging for ten minutes at intake.
5. **Coverage is audited, not re-created.** The detailed matrix in requirements.md identifies already covered T4–T14 paths. The new feature concentrates on preflight and full application access-store restart, plus the missing access callback variants.
6. **Negative assertions need a completed observation boundary.** Observe terminal rejection/deadline plus a drained preflight task before asserting no download/retained directory. Do not use an immediate zero-call check that could pass before asynchronous work starts. Filter call journals by submission and distinguish startup probes from per-link probes.
7. **Restart tests must cross the real lifecycle.** Persist state via /start and the mocked Telegram reply, close/reopen the context with the same store, and tap the original recorded callback. Missing owner notification can be simulated with a Telegram failure. Snapshot file content for unauthorized callback assertions; do not replace a real restart with an internal object reload.
8. **Protocol/timing confirmed by architecture.** A: Q-analyst-1 and api.md specify Whisper GET `/`, Ollama GET `/api/version`, any HTTP status reachable (body discarded), no redirect following, parallel probes, HEALTH_TIMEOUT=PT3S and timeout + 1 second aggregate bound. Startup is asynchronous. These decisions check transport reachability and intentionally do not reject HTTP 503/model loading. Owner A: Q-analyst-2 approves worker placement and bounded queue delay; no design question remains.
