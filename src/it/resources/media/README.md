# Local media fixtures

These synthetic recordings are generated by ffmpeg, contain a 440 Hz tone and no
user media, and are served by the functional harness's local WireMock proxy.
`MediaFixtures.recording(seconds, extension)` records the commands in Java and
reuses the files here. Tests never download a fixture from the internet.

M4A: 16 kHz sine input, AAC at 8 kbps, with the duration in the filename. Combined
MP4 adds a 16×16 black H.264 video stream at 1 fps. The short fixture WAV is mono
16 kHz signed 16-bit PCM for the explicitly permitted process-argument tests.
Success/conversion scenarios use real yt-dlp and ffmpeg; the WAV fixture is not
used as proof of successful conversion.

The HTML media pages are generated per scenario with JSON-LD VideoObject metadata
and a local contentUrl. The pages contain no competing HTML5 embed: that extractor
would discard the JSON-LD duration and append `(1)` to the title. This fixture
choice was verified against the installed yt-dlp 2026.10.26 extractor source.

Required tools: ffmpeg and yt-dlp on PATH. Missing tools fail the tests; scenarios
are not skipped and no dependencies are downloaded by the harness.
